# Jolene's Desktop

A personal portfolio website inspired by macOS, featuring an interactive desktop interface with folders and windows to explore projects, experiences, and interests.

**[View Live Website](https://jolene-k.vercel.app/)**

## Features

- macOS-inspired desktop interface with clickable folders and windows
- Sections for projects, experience, and more
- Responsive layout for desktop and mobile devices

## Planned Features

- Draggable windows
- Resizable windows
- Additional desktop interactions and UI improvements

## Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Build Tool:** Vite
- **Deployment:** Vercel

## Status

Currently a work in progress. The initial version is deployed, with additional features and improvements planned.
